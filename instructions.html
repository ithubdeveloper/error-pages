Error Pages Setup Instructions

This guide explains how to serve the custom pages in this folder on Nginx and Apache. It includes file placement, server configuration, and validation steps.

1. Files Included

  • 403.html
  • 404.html
  • 429.html
  • 500.html
  • 502.html
  • 503.html
  • 504.html
  • maintenance.html

Recommended deployment path: /var/www/error-pages.

2. Easy Install (Direct Git Clone)

Clone and deploy in one flow

cd /tmp
git clone https://github.com/ithubdeveloper/error-pages.git
sudo mkdir -p /var/www/error-pages
sudo cp /tmp/error-pages/*.html /var/www/error-pages/
sudo chown -R root:root /var/www/error-pages
sudo chmod 644 /var/www/error-pages/*.html

If your server has no Git access, upload these files manually and continue with server configuration.

3. Nginx Configuration

Example server block

server {
    listen 80;
    server_name example.com;

    root /var/www/html;

    # Custom error pages
    error_page 403 /error-pages/403.html;
    error_page 404 /error-pages/404.html;
    error_page 429 /error-pages/429.html;
    error_page 500 /error-pages/500.html;
    error_page 502 /error-pages/502.html;
    error_page 503 /error-pages/503.html;
    error_page 504 /error-pages/504.html;

    # Optional maintenance page (force 503 for all requests)
    # Uncomment this block during maintenance:
    # if (-f /var/www/error-pages/maintenance.flag) {
    #     return 503;
    # }
    # error_page 503 /error-pages/maintenance.html;

    location /error-pages/ {
        alias /var/www/error-pages/;
        internal;
    }
}

Reload Nginx

sudo nginx -t
sudo systemctl reload nginx

4. Apache Configuration

VirtualHost example

<VirtualHost *:80>
    ServerName example.com
    DocumentRoot /var/www/html

    Alias /error-pages/ "/var/www/error-pages/"
    <Directory "/var/www/error-pages">
        Options -Indexes
        AllowOverride None
        Require all granted
    </Directory>

    ErrorDocument 403 /error-pages/403.html
    ErrorDocument 404 /error-pages/404.html
    ErrorDocument 429 /error-pages/429.html
    ErrorDocument 500 /error-pages/500.html
    ErrorDocument 502 /error-pages/502.html
    ErrorDocument 503 /error-pages/503.html
    ErrorDocument 504 /error-pages/504.html

    # Optional: set maintenance page for 503
    # ErrorDocument 503 /error-pages/maintenance.html
</VirtualHost>

Reload Apache

sudo apachectl configtest
sudo systemctl reload apache2

5. Deploy and Validate

Copy files

sudo mkdir -p /var/www/error-pages
sudo cp *.html /var/www/error-pages/
sudo chown -R root:root /var/www/error-pages
sudo chmod 644 /var/www/error-pages/*.html

Quick validation checks

# Confirm pages are accessible through configured route
curl -I http://example.com/non-existing-page

# Trigger 404 and check body response
curl -s http://example.com/non-existing-page | head

Tip: Keep the /error-pages/ location internal on Nginx to prevent direct browsing. On Apache, keep directory listing disabled using Options -Indexes.
